# Исследовательские сценарии

Ручные прогоны сохранённых материалов и сравнение отдельных изменений. Это не рабочие службы и не обычные тесты проекта. Старые сценарии могут зависеть от интерфейсов прежней редакции; перед запуском требуется проверить их импорты и настройки.

Не использовать эксперимент как рабочую копию приложения. Результаты прогонов сохраняются в локальном `exports/`, который исключён из Git. Рабочие базы, ключи и настройки не копируются в исследовательские артефакты для публикации.
