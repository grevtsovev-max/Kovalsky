# История изменений Kovalsky

## 2026-09-29 — Очередь повторного анализа

- Отпечаток исходной ленты отделён от текста прочитанной статьи: очередной опрос источника больше не стирает анализ и счётчик повторов только потому, что в записи хранится полный текст страницы.
- Отложенные из-за лимита цикла проверки больше не считаются неудачной попыткой и явно показывают причину и ближайший цикл.
- Повторные материалы ограничены четырьмя за цикл, чтобы оставить бюджет для новых новостей.
- В карточке очереди показываются возраст материала, время последней обработки, счётчик реальных повторов и момент, с которого повтор готов к запуску.
- Снимки версий используются для однократного закрытия тех неизменённых материалов, которые уже прошли первоначальный и три повторных разбора до исправления сбрасываемого счётчика.

## 2026-09-29 — Исправления по самоаудиту

- Повторная версия материала по тому же каноническому URL сохраняется в `item_revisions`; изменённый материал снова проходит обычный отбор, а прежний разбор остаётся в снимке версии.
- Лимит Web Search стал общим: один запрос за настроенный интервал, сейчас 15 минут. Очередь чередует широкие темы, поиск первоисточника и наблюдение за сюжетами; отложенный вызов не считается неудачной попыткой.
- Если поисковый API и резервный RSS-поиск оба завершаются ошибкой, журнал сохраняет оба безопасных кода, чтобы отличать сбой API от отказа резервного источника.
- Для точного прочитанного сообщения в соцсети выдержка из заголовка сообщения может восстановить отсутствующую цитату, если сохранена атрибуция и факты отмечены как CLAIM/REPORT/OPINION. Свежие прежние отказы, удовлетворяющие тем же строгим условиям, переоцениваются один раз по новой версии фильтра.
- Фильтр готового текста распознаёт служебные фразы о неудачном поиске и несопоставленных материалах.
- Кабинет и нормативный снимок открывают базы только для чтения. Ошибки чтения отдельной статьи не переводят успешно полученную ленту в состояние сбоя.
- В замерах цикла отдельно выделен story watch. Постоянный запуск поддерживает целевой интервал между стартами, а метаданные проекта допускают фактически используемый Python 3.9.
- AI-фильтр обновлён до версии 22. Исходные базы, конфигурация, ключи, логи и архивы исключены из истории исходников.

Проверка: `python3 -m unittest discover -s tests -q` — 241 тест прошёл.
