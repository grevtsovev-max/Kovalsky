# Контракт редакции

Автоматическая публикация разрешена владельцем для каждого материала после первого фильтра. Редактура и проверки не блокируют выпуск. Одна доработка; затем версия с замечаниями либо резервный фрагмент исходника при фактической или технической проблеме. Ручного одобрения для обычного потока нет; причины и версии сохраняются без бесконечного повторения.

Ссылки из кабинета проходят первый тематический фильтр. Точный текст по отдельной явной команде владельца сохраняет административный путь доставки. Неизвестные результаты отправки повторять запрещено. Остановка агента имеет приоритет над любым запуском редакции.

Правила и примеры новой версии находятся в `EDITORIAL_RULES.md` и файлах пакета `newsroom/edition/`.
