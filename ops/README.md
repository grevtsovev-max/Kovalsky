# Служебные инструменты

- `deploy.sh` — штатная активация полного выпуска; сохраняет остановку владельцем и восстанавливает предыдущий выпуск при ошибке.
- `check_release.py` — сравнение исходников выпуска с Git; ничего не изменяет и не перезапускает. Код возврата: 0 — совпадение, 1 — расхождения, 2 — сравнение недоступно.
- `telegram_reader_setup.py` — настройка отдельного транспорта чтения Telegram.
- `jina/` — инфраструктура чтения источников.
- `agent-control.conf` — защита запуска службы при остановке владельцем.

`*_update.py`, соответствующие `.patch` и `*_base.json` — пакеты отдельных прежних обновлений с привязкой к базовому выпуску. Они сохранены для проверки истории и предусмотренного ими отката. Это не универсальный способ выкладки текущей рабочей копии; не применять старый пакет поверх произвольного выпуска.

Рабочие настройки, данные и постоянный запрет агента находятся отдельно от выпуска. Обновление не даёт разрешения включить остановленного агента.
