# Kovalsky Newsroom

Сервис собирает и сохраняет исходные материалы. Прежний редактор удалён: написание, редакторская проверка, исправления, дайджесты и автоматическая публикация отсутствуют. Новая реализация будет создана с нуля.

Темник и первый фильтр отбора продолжают работать. Кабинет показывает материалы, источники, расходы и ранее опубликованные посты. Исторические данные сохранены и не используются для написания.

Исходники находятся в `newsroom/`, тесты — в `tests/`. Настройки, ключи, журналы и рабочая база хранятся отдельно от Git. Безопасный пример настроек — `config.example.toml`.

Команды: `newsroom run`, `once`, `health`, `pending`, `filter-audit-export`, `dashboard`, `agent`. `admin-publish` сохраняет возможность отправить точный текст по явной команде владельца без генерации и редактуры.

Изменения `newsroom/` в main автоматически выкладываются на сервер. Отключённый агент нельзя включать без явной команды владельца. Архитектура описана в `AGENT_LOGIC.md` и `MODULES.md`.
