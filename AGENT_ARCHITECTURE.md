# Новостной поток

Сбор и первый фильтр → неизменяемые снимки → группировка → написание → однократная проверка поступлений → проверка кода и смысла → одна доработка при необходимости → выпуск текста с замечаниями либо резервного фрагмента исходника → штатная доставка.

Сбор и редакция работают параллельно. Редакцию защищает отдельная блокировка процесса. Новые материалы поступают независимо от текущей подготовки. Архив индексируется порциями без автоматической публикации старой истории.

`edition_materials` хранит версии исходников и очередь; `edition_jobs` — попытки и общий бюджет поиска; `edition_documents` — сюжеты, черновики и доставку; `edition_events` — версии и ход работы; `edition_checks` — привязанный к тексту результат проверок; `edition_lookups` — реально использованный локальный контекст.

Кабинет показывает исходники, версии, причины остановки и время. Повтор подготовки выполняется явным действием. После перезапуска незавершённое написание сохраняется как остановленное; готовая доставка восстанавливается по журналу, не повторяя неизвестные отправки.

Правила: `EDITORIAL_RULES.md`. Рабочие файлы: `newsroom/edition/policy.json`, `references.json`.
