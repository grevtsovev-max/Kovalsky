# Восстановление редакционного цикла, 28 сентября 2026

## Установлено

- Общая обработка запросов редактора и поиска: ограниченный повтор сетевых/429/5xx ошибок, безопасный конкретный код API без ключей, содержимого запросов и сообщений ошибки. Отказы 401/403 не обходятся. Статус последнего успешного разбора отделён от старых ошибок.
- Если API поиска недоступен, поиск переключается на публичный индекс Google News. Сниппеты не считаются прочитанным источником. Ошибки чтения найденных страниц больше не исчезают из диагностики. Даты извлекаются из метаданных и JSON-LD статьи.
- Проверка тематической релевантности теперь может отклонить постороннюю новость до ожидания первоисточника. Недостаток доказательств не означает нерелевантность местной новости. Дубли распознаются без требования заново доказывать уже опубликованное событие.
- Для задержанных местных материалов ищется прочитанный источник в архиве и через отдельный поиск: максимум два поисковых запроса за цикл, повтор для одного URL не чаще получаса. Совпадение темы проверяется предварительно и затем редактором. Непрочитанные страницы не получают READ.
- Оригинальные сообщения распознаются у настроенных авторитетных веб/RSS-изданий, а не только у исходных восьми брендов. Собственные сообщения настроенных СМИ в Telegram также могут быть источником; пересылки исключены. Происхождение центрального утверждения всё равно проверяется редактором.
- Перед созданием и штатной отправкой поста проверяются соответствие источника событию, атрибуция, стадия решения, история позиции или честное пояснение о пробеле, русский текст и флаг. Ошибки оформления возвращаются на исправление до трёх раз с передачей замечаний. Решение WAIT_FOR_CONFIRMATION больше не повышается автоматически до публикации.
- История ищется в локальном архиве; наличие полного внешнего исторического исследования не имитируется. Семантические проверки по-прежнему зависят от оценки модели и не являются математической гарантией.
- Истёкшие материалы снимаются с повторной проверки. Число ИИ-разборов за цикл ограничено 25. Кабинет показывает очереди и актуальную ошибку/последний успех редактора отдельно от доступности источников.

## Проверка

103 автоматических теста, включая сценарии недоступного API, резервного поиска, недоступного источника, сохранения релевантной местной новости, отбраковки посторонней, пересылок, истории позиции, стадии закона и блокировки ручной отправки.

Рабочий цикл 10:21–10:26 UTC: 23 успешных ИИ-разбора, без новых ошибок доступа. PRIMARY_RETRY сократился с 66 до 48; 2 старых WAITING_CONFIRMATION оставались до включения истечения срока. Всего в цикле: NOISE 47, PRIMARY_RETRY 2, DUPLICATE 1935, ARTICLE_SOURCE_ERROR 2, SOURCE_ERROR 2. Цикл занял 275 секунд при разгрузке очереди. Новый пост не создан. Это подтверждает обработку, но не означает, что все внешние источники доступны.

## Внешние ограничения

ТАСС возвращает защитную страницу; Investing/Finam блокируют часть чтений. Публичные Telegram-превью rian_ru/rgrunews недоступны. Отдельные веб/RSS-источники тех же изданий включены. Наличие альтернативы не доказывает, что каждая конкретная новость найдена. Оставшаяся очередь продолжает штатную повторную обработку. Причину прежних HTTP 403 воспроизвести не удалось: и диагностические запросы, и рабочие запросы прошли; при повторении отказ будет сохранён с доступным безопасным кодом API.

Опубликованные сообщения и параметры доступа не изменялись. Резервные копии находятся в data/reliability-*.
