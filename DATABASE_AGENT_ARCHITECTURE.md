# Данные новой редакции

Новые таблицы: `edition_materials`, `edition_jobs`, `edition_documents`, `edition_events`, `edition_checks`, `edition_lookups`; локальный индекс `edition_search`.

Исходники, попытки, черновики, проверки и доставка связаны идентификаторами. Допуск хранит хеши текста, исходников и правил. Старые таблицы остаются ради сохранения истории и совместимости; их редакторские выводы не передаются новому модулю.

Доставка использует существующие `posts`, `stories`, `publication_attempts`, `delivery_events`. Неизвестный результат блокирует повтор; сохранённый ответ позволяет восстановить подтверждённую отправку.
