# Резерв без рекламных призывов

Обновление `promo-recovery-v1` исправляет резервный выпуск по примеру сообщения №498.

Код замечает явные обращения к читателю («Подключите», «Подайте заявку») во всех блоках готового текста. Очистка исходных фрагментов удаляет такие предложения, включая предложения с начальным эмодзи, сохраняя последующие факты. Сообщения о совершённых действиях компании и описания функций не исключаются по этому признаку.

Дословный резерв не выпускается для группы с несколькими самостоятельными ключами событий: такие группы продолжают сохранённый короткий редакторский этап. Планировщик и полная редактура повторно не запускаются. Неизвестная доставка и остановка владельцем сохраняют приоритет.

Проверка: 173 редакторских теста, включая рекламный исходник, сохранение следующего факта и отказ от бессвязной сборки нескольких событий. Сохранённый черновик №498 получает три программных замечания; его группа больше не получает дословный резерв. Проверка проведена без запросов AI и публикации.

Выпуск накладывается на текущую активную версию, меняя только `source_text.py`, `short_release.py`, `formatting.py` и этот документ. Реестр выпуска сохраняет предыдущую версию для отката. Опубликованные сообщения автоматически не переписываются.
