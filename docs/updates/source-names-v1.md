# Названия источников

В справочнике источников используется необязательная колонка «Название для публикации». Она задаёт отображаемое название канала или издания, не переименовывая объект наблюдения в колонке «Название». Для одинакового URL название общее во всех вкладках. Противоречащие друг другу непустые названия отклоняют новую копию справочника; последняя корректная копия остаётся доступной.

Явное название имеет приоритет над старой подписью «Канал @…» и над технической подписью для вкладки «Лица». Если поле пустое, сохраняется прежнее поведение. Суффиксы «(Telegram)» и «(RSS)» не включаются в строку «Источник».

Новые материалы сохраняют название источника при получении. Ссылка в строке «Источник» ведёт на конкретный использованный материал; название фактического издания для найденных через агрегатор материалов сохраняет приоритет. Исторические снимки, опубликованные сообщения, правила и референсы не переписываются. Агент, остановленный владельцем, не включается.

Проверены чтение новой колонки, общие URL в разных вкладках и при разном порядке строк, сохранение мониторинга лиц, отказ от противоречивых названий и независимость названия от ссылки. Обновление выкладывается поверх текущего выпуска только файлами source_registry.py и edition/formatting.py.
