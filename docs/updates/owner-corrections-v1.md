# Исправление опубликованного сообщения

По явной команде владельца:

```
python -m newsroom.edition.corrections --config <рабочая-конфигурация> --message-id <номер-сообщения>
```

Команда использует сохранённые исходники и текущие правила. Планировщик выделяет одно профильное событие, редактор готовит текст, независимый проверяющий проверяет его. Разрешена одна доработка. Несколько самостоятельных событий требуют отдельного решения владельца; они не превращаются автоматически в несколько новых публикаций.

Сообщение редактируется на месте через editMessageText. Старый текст, исходный редакционный документ, кандидат, доказательства, проверки и ответ Telegram сохраняются в edition_corrections и edition_events. Кабинет показывает исправленную версию. Исходная доставка и прежние проверки сохраняются.

При недоступности подготовки или проверки исходный пост остаётся без изменений. Повторная команда продолжает сохранённого кандидата. Неизвестный результат редактирования блокирует слепой повтор и требует сверки с Telegram. Остановка владельцем имеет приоритет; команда не включает агента. Автоматической перепроверки всех публикаций нет.
