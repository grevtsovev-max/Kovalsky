# Исторические проверки прежней редакции

Здесь сохранены 45 тестовых модулей удалённой редакции и четыре вспомогательных файла. Расширения `.py.txt` и `.json.txt` исключают их из обычного запуска. Архив не является рабочим кодом; восстанавливать старые модули для его запуска не нужно.

Также сохранены полные исходные версии смешанных файлов: проверки темника, источников, ресурсов, первого фильтра, учётных данных ИИ, остановки агента и счётчиков кабинета. Их действующие части остаются в `tests/`.

В архив перенесены проверки удалённых `process_item`, редакторского бота, старых дайджестов, старого обучения и повторного редакторского конвейера. Прежние проверки кеша `Work.execute` также исторические: действующий исполнитель напрямую вызывает функцию и не использует прежние `key`/`ttl` для кеширования.

Действующие проверки новой редакции находятся в `tests/test_edition_*.py`. Удаление старых точек входа проверяет `tests/test_editorial_removed.py`; остановку владельцем — `tests/test_agent_control.py`; отказ до загрузки источника — `tests/test_negative_keywords.py`; последовательные счётчики — `tests/test_sequential_counters.py` и проверки кабинета.

Полный запуск: `python -m unittest discover -s tests` в окружении с установленными зависимостями проекта. Архивные файлы не исполняются и не включаются в этот набор.
